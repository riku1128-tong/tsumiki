# そらの積み木鉄道

雲の上に浮かぶ4つの積み木の島を、積み木の機関車がぐるりとめぐる three.js のジオラマです。

## 見どころ

- **えきまえ島**: 駅（ホーム、屋根、看板、今の時刻を指す時計塔）、三角屋根の町、風車
- **たき山島**: 雪をかぶった山、針葉樹の森、湖。湖の水は滝になって雲の海へ落ちていきます
- **はなぞの島**: 観覧車、噴水、ベンチ、花壇、桜
- **うみべ島**: 海、砂浜、小舟、回る灯台。こちらの海からも滝が流れ落ちます
- 島と島のあいだは、風船で吊った橋でつながっています
- 機関車は駅に止まってから発車し、煙を吐きながら島をめぐります
- 昼・夕焼け・夜を切り替えられます（夜は窓や灯台に明かりがつきます）

## 操作

| 視点 | 操作 |
|---|---|
| ぐるっと見る | ドラッグで回転、ホイール／ピンチでズーム。島の名前を押すとその島へ移動 |
| 機関車を追う | カメラが列車の後ろをついていきます |
| 飛んでみる | 竹とんぼの子を操作して空を飛べます |

「飛んでみる」のときのキー操作:

| キー | 動き |
|---|---|
| W / S（↑ / ↓） | 前へ／うしろへ（押し続けると加速） |
| A / D（← / →） | 向きを変える |
| Space | 上昇 |
| Shift | 下降 |
| ドラッグ / ホイール | まわりを見る／カメラの距離 |
| Esc | 飛ぶのをやめる |

スマホでは、画面上のスティックと「上昇／下降」ボタンで操作できます。

## ローカルで動かす

ビルドは不要で、ファイルは `index.html` ひとつだけです。three.js は CDN（jsDelivr）から ES モジュールとして読み込みます。モジュールの読み込みがあるため、ファイルを直接開くのではなく、簡単な HTTP サーバー経由で開いてください。

```bash
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。
